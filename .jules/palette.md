## 2024-05-24 - Improve Tooltip Accessibility for Overlay Close Buttons
**Learning:** Adding `Tooltip` and explicit `aria-label` to standalone Radix UI overlay close buttons (like those in `Dialog` and `Sheet`) significantly improves context for screen readers over visually hidden text, and gives better discoverability for sighted users. The native Radix UI `.Close` elements accept `aria-label` which allows us to drop the `sr-only` span pattern.
**Action:** Always prefer wrapping `size="icon"` or icon-only buttons in explicit Tooltip components, using `TooltipProvider` locally if needed, and rely on `aria-label` directly on the trigger element rather than appending `<span className="sr-only">`.
