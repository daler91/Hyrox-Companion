## 2024-11-20 - Tooltip Accessibility\n**Learning:** In this repository, when adding tooltips to isolated elements (e.g., icon-only buttons with `size="icon"`), explicitly include a local `<TooltipProvider>` alongside `<Tooltip>`, `<TooltipTrigger asChild>`, and `<TooltipContent>` to ensure the tooltip context is available and renders correctly. To make tooltips accessible on disabled buttons, do NOT use the native `disabled` attribute or wrap them in a focusable `<span>` (which breaks semantic meaning and ARIA associations). Instead, use the `aria-disabled` attribute directly on the `<Button>`, manage the visual state with Tailwind classes (e.g., `aria-disabled:opacity-50 aria-disabled:cursor-not-allowed`), and manually prevent the action in the `onClick` handler (e.g., `if (!canExecute) e.preventDefault()`). This keeps the button focusable, triggers the tooltip natively, and allows screen readers to correctly announce it as disabled.\n**Action:** Use `aria-disabled` for disabled buttons with tooltips.
